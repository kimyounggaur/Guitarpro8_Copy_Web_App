# 구현 선택과 브라우저 제약

| 항목 | 적용한 동작과 이유 |
| --- | --- |
| 제품 시각 언어 | TabScore 이름, 자체 SVG 아이콘, 슬레이트·청록·앰버 색상 체계를 사용한다. 사용자 보유 R3/R4 화면을 회귀 기준으로 삼았다. |
| 인스펙터 폭 | 기본 232px로 폼 입력 공간을 확보한다. 사용자가 192~340px로 조절할 수 있다. |
| 자동화 | Global View와 함께 볼 수 있도록 F10으로 여는 독립 도크로 둔다. 전체 높이는 악보 최소 높이 안에서 조정된다. |
| 문서 탭 순서 | 클릭·단축키 이동, 닫기/다른 탭 닫기/오른쪽 탭 닫기를 제공한다. 드래그 순서 변경은 후속 항목으로 기록한다. |
| 파일 선택 | File System Access 지원 브라우저는 해당 API를 사용하고, Safari 등에서는 파일 선택·다운로드로 연결한다. |
| 오디오 저장 | 악보에는 파일 참조만 저장한다. 다시 열면 원본 녹음 파일을 재연결한다. 음량·음소거·오프셋은 현재 연결 세션에 적용된다. |
| 녹음 동기화 | 실제 초 단위 위치, 오프셋과 파형 탐색을 지원한다. 가변 템포 워핑과 카운트인 동시 재생은 지원 범위를 안내한다. |
| 장치 | 라인 입력은 브라우저 마이크 권한과 스트림 정리를 구현했다. 실제 오디오 하드웨어와 Fretlight 프로토콜은 검증하지 않았다. Fretlight 버튼은 노출하지 않는다. |
| 후속 음악 기능 | 가사 기보, 번호 보표 등 기반 엔진이 지원하지 않는 기능은 실행 가능한 동작과 구분해 비활성 또는 비노출 상태다. |
