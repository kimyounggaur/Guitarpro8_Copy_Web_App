# 반응형·성능 검증

2026-11-24 Linux x64, Node 24.22.3에서 배포 빌드를 측정했다. 편집·커서 p95는 입력 50회에서 계산했다. 힙 증가는 편집 20회 전후 GC 이후의 차이이며, 음수는 초기 측정보다 작아졌음을 뜻한다.

| 악보 | Chromium | 편집 p95 | 커서 p95 | 힙 증가 | 재생 4초 긴 작업 | 파일 바이트 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| Performance 1×32 | 153.0.8010.0 | 13.2ms | 15ms | -210852 | 0 | 9252 |
| Performance 8×100 | 153.0.8010.0 | 25.8ms | 14.4ms | -2611492 | 0 | 207120 |
| Performance 20×300 | 153.0.8010.0 | 55.3ms | 14.2ms | -17988168 | 1 | 1527773 |

CI와 같은 Chromium 149.0.7827.55로 8트랙×100마디를 별도 실행했다. 편집 p95 29.8ms, 커서 15.9ms, 힙 −2,729,364B, 재생 긴 작업 0회였다. 브라우저 버전이 다른 표의 실행과 구분해 기록한다.

같은 배포 빌드의 8트랙×100마디를 로드하고 첫 화면까지 기다리는 자동화 경과 시간은 1,068ms였다. 1.5초간 프레임마다 도크 크기 조절 키 이벤트를 보내는 검사에서 rAF 60.1fps, 32ms 초과 간격 0회였다. 개요를 가로로 스크롤하는 검사에서는 57.4fps, 32ms 초과 간격 2회였다. 이 수치는 가상 실행 환경의 프레임 콜백 간격이다. 실제 디스플레이와 포인터 장치에서의 프레젠테이션 지연은 별도다.

1024×768, 1280×768, 1440×900, 1920×1080, 2560×1440 DPR2에서 확인했다. 확대율 80·100·125%에 대응하는 CSS 뷰포트와 DPR 조합 15개에서 전체 가로 넘침이 없었고, 재생·실행취소와 오버플로 기능을 사용할 수 있었다. 이 검사에서는 브라우저의 네이티브 확대 UI를 직접 조작하지 않았다.

UI 런타임 의존성을 추가하지 않았다. 새 아이콘은 SVG이며 전체 아이콘 패키지를 가져오지 않는다. 통합 배포 빌드는 주 JS 약 772KB, gzip 약 243KB, CSS gzip 약 11.4KB다. 이전 R9 주 JS gzip 약 218KB와 비교할 수 있다.

```sh
pnpm test:perf
pnpm test:perf --grep '8 tracks'
pnpm exec playwright test --config playwright.perf.config.ts --grep 'shell startup'
```
