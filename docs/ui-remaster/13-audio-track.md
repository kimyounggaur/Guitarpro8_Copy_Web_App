# Phase 13 · 로컬 오디오 트랙

## 기존 도메인과 지원 범위

기준 커밋 `46ede05`의 `Score.audioTrack`과 네이티브 검증기는 파일 참조 `{ id, name, embedded }`를 보존한다. 합성 악기용 transport, 펼친 마디 순서, 틱↔초 템포 지도는 이미 있었고, 로컬 음원을 읽거나 재생하는 경로는 없었다.

| 기능 | 기준 커밋 | 도크의 동작 |
|---|---|---|
| 파일 선택·복호화 | 미지원 | 도크의 Add/Replace/Relink 또는 파일 드롭. 브라우저의 AudioContext가 파일을 실제로 디코딩한다. 잘못된 파일을 선택하면 기존 음원을 유지한다. |
| 파형 | 미지원 | 실제 PCM에서 채널별 최소·최대 피크를 구한다. 긴 파일은 샘플 읽기 사이에 UI에 제어권을 돌려주며, 최대 8,192개 구간을 보관한다. Canvas에는 줌으로 보이는 범위만 그린다. |
| 재생·이동 | 악보 합성·세션 seek만 지원 | Preview audio로 원음을 듣거나 Follow score playback으로 악보의 경과 초 위치에 맞춘다. 마우스·터치 이동과 방향키는 같은 초 단위 seek 콜백을 사용한다. |
| 시간·믹스 조절 | 미지원 | Offset은 음원의 시작 시간을 초 단위로 옮긴다. Gain과 Mute는 음원 전용 출력에 적용한다. 줌·레벨·오프셋은 현재 세션 설정이다. |
| 타임라인 | 악보 데이터만 제공 | 펼친 재생 순서와 기존 tempo map에서 마디 위치를 구한다. 편집 커서는 노랑, 재생/미리듣기 위치는 파랑, 선택 반복 범위는 반투명 파랑으로 표시한다. |
| 템포 동기화 | 미지원 | Follow는 원래 속도의 음원을 경과 시간에 맞춘다. 오디오 워핑, 싱크 지점으로 악보 템포 조종, 원음의 피치 변환과 마스터 믹서 자동화는 지원하지 않는다. 카운트인이 켜지면 독립 미리듣기만 허용한다. |
| 저장·다시 열기 | 세 필드만 보존 | 새 파일은 `embedded:false`로 저장한다. 파일 바이트와 파일 시스템 핸들은 저장하지 않는다. 네이티브 파일을 다시 열고 Relink audio로 원본을 선택한다. |

음원 교체·제거·문서 변경 시 이전 AudioBufferSource와 출력 노드를 분리하고 디코딩 컨텍스트를 닫는다. 이전 선택의 느린 디코딩이 새 음원을 덮어쓰지 않도록 취소 신호와 문서·참조 ID를 확인한다. 음원 로드·출력에 object URL을 생성하지 않는다. 도크를 접는 동작은 같은 문서의 컴포넌트를 유지하고 `visible`만 바꾼다.

## 검증

`src/test/fixtures/files/audio/pulse.wav`는 8kHz 모노 PCM 1초, 220Hz 시험 신호다. 브라우저 테스트에서 이를 실제 선택해 길이, 파형 생성, preview 재생 위치 진행, seek 콜백, 잘못된 교체, 참조 제거와 자원 해제를 확인한다. 파형 단위 테스트는 두 채널의 부호 있는 극값, 마지막 구간, 취소, 화면 좌표 역변환을 검증한다. 빈 도크와 파형이 있는 도크의 이미지는 Playwright 결과에 첨부한다.
