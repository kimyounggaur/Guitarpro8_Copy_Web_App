# UI 리마스터 검증 기록

2026-11-24 승인된 R3 셸 4종과 R4 악보 8종을 `approved-r3-r4`에 보존했다. R4 악보 8종은 로컬에서 생성한 독립 악보 스냅샷과 RGB 픽셀이 모두 같았다. 수동 데모의 개발용 제목은 TabScore Study로 정리했다. 새 UI의 기준은 데스크톱 크기 4종, 악보 8종, 핵심 장면 8종의 총 20개 Linux 스냅샷이다.

첫 생성 환경 Chromium 153과 CI의 149 사이에서 텍스트 영역의 기본 크기 조절 손잡이 32픽셀 차이를 검토했다. 최종 기준 20장은 CI의 Playwright 1.61.1 Noble 컨테이너와 Chromium 149.0.7827.55에서 캡처했다. 로컬 이미지와 나란히 비교해 UI 12장의 글꼴과 안티앨리어싱 차이, 홈 상태 푸터의 1px 높이 차이를 확인했다. 794×1123 악보 8장의 비교 차이는 장당 5~55픽셀이었고 배치는 같았다. CI의 첫 캡처와 재시도의 PNG 20장은 모두 바이트 단위로 일치했다.

최종 로컬 타입 검사와 단위 테스트 583개가 통과했다. 통합 Chromium 브라우저·오디오 회귀 116개가 통과했다. 이후 같은 파일 ID를 가진 복사본·다른 이름 저장·복구본을 함께 여는 추가 재현 검사를 통해 파일 바인딩과 독립 복구를 보완했다. 원본과 각 편집본의 음표 및 디스크 저장 결과를 확인했다. Linux WebKit 26.5에서는 주요 새 흐름 30개와 연결된 오디오 도크 1개가 수정 후 통과했다. macOS Safari 27.2의 별도 SafariDriver 검사는 시작 화면·입력·잘못된 SVG 좌표·전체 넘침을 확인한다. 확장된 문서 전환·키보드 리사이즈·명령 입력은 원격 CI 결과로 확인한다.

원본 상용 앱의 참조 파일을 제품에 포함하지 않았다. 승인된 자체 앱 화면과 요구된 상호작용을 비교했다. [구현 선택과 제약](19-intentional-differences.md)에 탭 순서·오디오 파일·실장치 검증 범위를 기록했다.
