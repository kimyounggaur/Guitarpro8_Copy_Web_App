# 악보 형식 지원 범위

## MusicXML 4.0 score-partwise

| 항목 | 읽기 | 쓰기 |
|---|---|---|
| 피치와 악기 | 파트 이름, MIDI 프로그램, 유음·현악·타악기 및 악기별 MIDI 번호. 현악기 줄·프렛이 없으면 튜닝과 카포의 연주 가능 범위에서 배치 | 파트 이름, MIDI 프로그램, 현악기 줄·프렛, 타악기 GM 번호 |
| 리듬 | 쉼표, 점 0~2개, 셋잇단음 등을 포함한 actual/normal 비율, 64분음표까지의 음표 종류 또는 duration으로 환산 | 쉼표, 기본 음 길이, 점, 잇단음. 복합 잇단음과 480틱으로 나누어떨어지지 않는 값은 반올림 |
| 성부·화음 | voice 등장 순서로 최대 4성부, chord 결합, backup/forward에 따른 시작 위치와 쉼표 보충 | 최대 4성부, chord 및 backup 분리. 큰 보표의 위·아래 보표는 앱의 MIDI 60 기준 |
| 붙임줄 | tie/tied의 시작·끝과 연속 연결 | tie/tied의 시작·끝. 현악기 줄과 유음악기 실음 기준 |
| 박자·조·기보 | 직전 박자와 조 상속, 조표·장단조·divisions, G/F/타악기 음자리표, 8vb, 이조, 튜닝·카포 | 박자·조 변경, G/F/타악기 음자리표, 8vb, 이조·튜닝·카포 |
| 반복과 점프 | 도돌이, 다른 괄호, Segno·Coda·Fine, D.C./D.S./D.S.S. 및 Coda/Fine 조건 | 같은 기능을 barline 및 direction의 표시와 sound 속성으로 저장 |
| 템포 | sound tempo와 metronome BPM을 위치별 지점으로 변환 | 템포 지점의 quarter BPM. 템포 램프 모양은 분리 보존하지 않음 |
| 효과 | 코드 이름, 해머링·풀오프, 벤딩 높이, 슬라이드·슬러, 악센트·스타카토, 일부 꾸밈음 | 코드 이름, 해머링, 벤딩 높이, 슬라이드·슬러, 악센트·스타카토, 일부 꾸밈음 |
| 파일 형식 | XML과 컨테이너를 포함한 ZIP(.mxl) | 압축하지 않은 .musicxml |

왕복 비교에는 위 항목에서 지원하는 음악 정보가 포함된다. 파일·트랙 ID, 앱 확대율, 독립된 파트 박자, 네 성부를 초과한 자료, 지원하지 않는 표기 및 전체 효과 곡선은 비교에서 제외된다. 가져오기가 지원하지 않는 요소를 건너뛰면 종류별 개수를 알려준다. XML 6개 픽스처는 `src/test/fixtures/files/musicxml/`에 있다.
