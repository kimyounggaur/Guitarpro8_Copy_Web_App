# 후속 UI 리마스터

R0~R9에서 적용한 악보 모델·기보·입력·재생·파일 처리를 후속 UI 작업의 기준으로 삼는다. 기능 검증에는 R 단계의 단위·브라우저 회귀 테스트를 사용한다. UI Phase에서 음악 규칙은 그대로 유지한다.

| Phase | 앞서 도입한 동작을 확인할 항목 |
| --- | --- |
| 6 | 앱 메뉴와 명령 활성 상태 |
| 7 | 도구줄 넘침, LCD 템포 |
| 10 | 보이는 악보 페이지, 스크롤 추적 |
| 12 | 실시간 믹서, 파일에 저장되는 효과 |
| 14 | 시작 화면과 복구 흐름 |
| 15 | 등록된 명령과 검색 |
| 16 | 편집 도구, 기본 스타일 |
| 17 | 포커스와 접근 가능한 이름 |
| 18 | 성능 지표와 대형 악보 |

기획 범위와 검증 절차는 [리팩토링 설계서 부록 C](refactoring-design.md)와 [UI 플레이북](<../../GuitarPro8-UIUX-리마스터-바이브코딩-프롬프트(GPT56Ultra).md>)을 참고한다.
