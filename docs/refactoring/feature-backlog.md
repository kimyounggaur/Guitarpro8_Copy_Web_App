# 후속 기능

아래 기능은 설계서 R9에서 노출을 정리하고 별도 작업으로 인계하는 항목입니다.

| 기능 | 우선순위 | 확인할 선행 조건 |
| --- | --- | --- |
| 여러 문서 탭·파일 보호 | 높음 | 문서별 이력, 저장·복구 상태와 잠금 정책 |
| 가사와 악보 위 코드 다이어그램 | 중간 | 저장 형식 호환성, 인쇄·페이지 배치 |
| 여러 마디 쉼표 표기 | 중간 | 마디 반복 기호와 별도 모델, 입력과 MusicXML 왕복 |
| 디자인 모드·환경설정 | 중간 | 사용 가능한 스타일, 기본값과 문서별 값의 범위 |
| 오디오 트랙·오디오 내보내기 | 이후 | 재생 동기화, 음원 권리, 출력 형식 |
| MIDI 건반 입력 | 이후 | 브라우저 권한, 레이턴시, 녹음·편집 정책 |
| 선택 사운드폰트 R5-B | 이후 | 라이선스, 8MB 이하 다운로드, 첫 재생 검증 |
