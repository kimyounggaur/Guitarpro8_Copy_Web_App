# 스타일 설정 적용 범위

용지 프리셋과 화면·인쇄용 페이지는 같은 폭·높이를 사용한다. 문서별 스타일은 악보 파일에, 새 악보의 기본 스타일은 환경설정에 저장한다. 아래 표는 저장 필드 109개와 프리셋 선택을 포함한다.

(가)는 현재 조판에서 사용한다. (나)는 이번 단계에서 입력 경로를 연결했다. (다)는 편집 화면의 조작 항목을 숨긴 설정이다. 파일 호환을 위해 저장값은 유지한다.
